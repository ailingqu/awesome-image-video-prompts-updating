## 怎么使用提示词

1. 打开任意卡片，复制 **Prompt** 下面的整段提示词。
2. 打开 **[vinano.ai](https://vinano.ai?utm_source=github&utm_medium=readme&utm_campaign=awesome-image-video-prompts-updating&utm_content=how-to-zh)**，粘贴到图片或视频生成框并选择模型。
3. 把品牌、产品、城市、人物等占位内容换成你自己的，然后生成。
4. 要在代码里用？全部提示词也在 [`prompts/prompts.json`](prompts/prompts.json)；搭建自己的生成器可参考系统提示词：[EN](prompts/system-prompt-en.md) · [中文](prompts/system-prompt-zh.md)。
